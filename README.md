🏥 Virtual Clinic – Medical Appointment Management System

Web application developed as an academic project to manage medical appointments, patient records, and professional schedules for a private healthcare clinic.

The system supports multiple user roles and provides a complete workflow for appointment scheduling and agenda management.

🚀 Project Overview

This application replaces a manual appointment system with a digital platform that allows patients, doctors, operators, and administrators to interact efficiently through a role-based interface.

Each user type has access to specific features according to their responsibilities within the clinic.

🛠️ Tech Stack

Angular 16

Angular Material

TypeScript

HTML5 / CSS3

Node.js

⚙️ Environment & Setup
Node.js Version

This project was developed using Node.js v16.14.0.
Using this version is recommended to ensure correct execution.

Run the Project

From the root directory:

npm run dev

👥 User Roles & Features
👤 Guest

View general information about the system

Register as a patient

Log in to access functionalities

🧑‍⚕️ Patient

-Request new medical appointments

-View upcoming and past appointments

-Edit personal information (email, password, phone, health coverage)

-Automatic coverage assignment based on registration data

👨‍⚕️ Doctor

-View scheduled appointments by date

-Access patient details and appointment notes

-Manage availability by defining working days and time ranges

🧑‍💼 Operator

-Create patient accounts

-Assign appointments

-View and modify doctors’ schedules

-Access daily appointment lists

-Filter appointments by date

👑 Administrator

-Full user management (patients, doctors, operators, admins)

-Coverage management (create, edit, delete with validations)

-Medical specialty management

-System-wide configuration and control

📅 Appointment Management

-Step-by-step appointment request flow

-Specialty, professional, date, and time selection

-Availability validation

-Confirmation pop-ups with appointment details

-Appointments ordered chronologically

🔐 Security & Permissions

-Role-based access control

-Restricted access to administrative features

-Session handling and user validation

-Editable fields limited by user role

🎨 UI & UX

-Built with Angular Material

-Responsive layout

-Pop-ups for confirmations and notifications

-Clear navigation menus based on user role

-Persistent header and footer with clinic information
